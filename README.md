# Rick & Morty · práctica para la técnica de Humand

SPA con React + Vite, TypeScript strict, MUI, react-hook-form, Zod, TanStack Query,
json-server y Biome.

```bash
npm install
npm run api        # json-server en http://localhost:3001 (db.json)
npm run dev        # la app en http://localhost:5173
npm run typecheck  # TypeScript
npm run lint       # Biome
```
